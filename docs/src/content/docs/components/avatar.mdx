## Content

An avatar shows, in this order: an `image` on top, otherwise an `icon`, otherwise `text` — or
anything you put in the default slot.

- `image` takes a URL or an image imported in Astro. Imported images are optimized with
  `astro:assets`: resized to the avatar's size, with a 2× version for sharp screens.
- With both `image` and `text`, the text sits under the image. If the image fails to load, it's
  removed and the text shows instead:

<Preview>
  <Avatar image="/missing-photo.jpg" text="JB" color="primary" label="Jakub Banach" />
</Preview>

```astro
<Avatar image={user.photoUrl} text="JB" color="primary" label="Jakub Banach" />
```

The steps are `xs` 24px, `sm` 32px, `default` 40px, `lg` 48px and `xl` 56px; a number sets
pixels. Text and icons scale with the size.

## Variants and colors

Variants and colors work like on [`Button`](/components/button/) and [`Chip`](/components/chip/):
`tonal` (default) is a light tint, `flat` and `elevated` are solid, `outlined` has a border.
Without a `color` the avatar is neutral.

## Accessibility

Give the avatar a `label` with the person's name — it's announced as an image with that name
(`role="img"`), instead of reading out initials like "J B". Use `alt` only when the image itself
shows something the label doesn't describe.

## API

| Prop      | Type                                                    | Default   |
| --------- | ------------------------------------------------------- | --------- |
| `image`   | `string` (URL) or an imported image                     | —         |
| `alt`     | `string` — alternative text of the image                | `''`      |
| `text`    | `string` — e.g. initials                                | —         |
| `icon`    | icon component (as for [`Icon`](/components/icon/))     | —         |
| `size`    | `xs` · `sm` · `default` · `lg` · `xl` · number (px)     | `default` |
| `variant` | `tonal` · `flat` · `elevated` · `outlined` · `text`     | `tonal`   |
| `color`   | `primary` · `secondary` · `success` · `warning` · `info` · `error` | — (neutral) |
| `rounded` | `xs` · `sm` · `default` · `lg` · `xl` · `full`          | `full`    |
| `label`   | `string` — accessible name                              | —         |
| `class`, `style` | `string` — `style` is added after the size       | —         |

**Slot:** default — custom content instead of `icon` / `text`.
