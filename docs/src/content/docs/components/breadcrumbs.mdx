```astro
---
import { Breadcrumbs } from 'bws-astro-ui';
import { ChevronRight } from 'bws-astro-ui/icons';
---

<Breadcrumbs
  items={[
    { title: 'Home', href: '/' },
    { title: 'Blog', href: '/blog' },
    { title: 'Astro tips' },
  ]}
/>

<Breadcrumbs items={…} divider={ChevronRight} color="primary" />
```

The last item is the current page: it's plain text marked with `aria-current="page"`. The others are
links, unless they're `disabled` or have no `href`. The whole thing is a `<nav>` with an ordered
list, and the dividers are hidden from screen readers.

## Items and dividers

| Item field | Description                                   |
| ---------- | --------------------------------------------- |
| `title`    | the text                                      |
| `href`     | makes the item a link (not on the last item)  |
| `icon`     | any icon `<Icon>` accepts, before the text    |
| `disabled` | shown as text, not a link                     |

`divider` takes text (`/` by default, `›`, `·`…) or an icon component like `ChevronRight`. Without
a `color`, links are muted text that darkens on hover; with one, they take that color.

## Structured data

With `schema`, the component also adds schema.org `BreadcrumbList` structured data (JSON-LD), which
search engines like Google use to show the path in search results instead of a bare URL:

```astro
<Breadcrumbs items={items} schema />
```

Search engines need full addresses, so relative links are resolved against `site` from your Astro
config — set it, or the build uses `http://localhost:4321`:

```js title="astro.config.mjs"
export default defineConfig({
  site: 'https://example.com',
});
```

Use `schema` on one breadcrumb trail per page.

## API

| Prop      | Type                                                    | Default      |
| --------- | ------------------------------------------------------- | ------------ |
| `items`   | breadcrumb items (see [Items](#items-and-dividers))     | required     |
| `divider` | `string` or an icon component                           | `/`          |
| `color`   | link color: a [theme or custom color](/guides/themes/#custom-colors) | muted text |
| `label`   | `string` — accessible name of the `<nav>`               | `Breadcrumb` |
| `schema`  | `boolean` — add JSON-LD structured data                 | `false`      |
| `id`, `class` | `string`                                            | —            |
