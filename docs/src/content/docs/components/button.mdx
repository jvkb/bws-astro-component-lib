Renders a `<button>`, or an `<a>` when it gets an `href`.

```astro
---
import { Button } from 'bws-astro-components';
---

<Button>Save</Button>
<Button href="/contact">Contact</Button>
```

works without defining shades.

## Icons

Put an [`Icon`](/components/icon/) inside — without a `size` it follows the button's text size.

<Preview>
  <Button>Next <Icon icon={ArrowRight} /></Button>
  <Button variant="outlined" color="secondary"><Icon icon={Download} /> Download</Button>
</Preview>

```astro
---
import { Button, Icon } from 'bws-astro-components';

---

<Button>
  Next <Icon icon={ArrowRight} />
</Button>
```

## Links, forms and disabled buttons

<Preview>
  <Button href="#links-forms-and-disabled-buttons">Link</Button>
  <Button type="submit" variant="tonal">Submit</Button>
  <Button disabled>Disabled</Button>
</Preview>

```astro
<Button href="/pricing" target="_blank">
  Link
</Button>
<Button type="submit">Submit</Button>
<Button disabled>Disabled</Button>
```

A `<button>` defaults to `type="button"`, so it never submits a form by accident — set
`type="submit"` for that. With `href` the button takes link attributes (`target`, `rel`,
`download`…), without it button attributes (`type`, `disabled`, `name`, `form`…); TypeScript flags
mixing them, e.g. `disabled` on a link.

## Overriding classes

Classes passed in `class` replace the conflicting defaults (merged with
[tailwind-merge](https://github.com/dcastil/tailwind-merge)):

<Preview>
  <Button class="rounded-none tracking-wide uppercase">Custom</Button>
</Preview>

## API

| Prop      | Type                                                               | Default    |
| --------- | ------------------------------------------------------------------ | ---------- |
| `variant` | `elevated` · `flat` · `tonal` · `outlined` · `text`                | `elevated` |
| `color`   | `primary` · `secondary` · `success` · `warning` · `info` · `error` | `primary`  |
| `size`    | `xs` · `sm` · `default` · `lg` · `xl`                              | `default`  |
| `rounded` | `xs` · `sm` · `default` · `lg` · `xl` · `full`                     | `default`  |
| `block`   | `boolean` — full width                                             | `false`    |
| `href`    | `string` — renders an `<a>`                                        | —          |
| `class`   | `string` — merged over the defaults                                | —          |

Any other attribute goes to the `<button>` / `<a>`. **Slot:** default — the content.
