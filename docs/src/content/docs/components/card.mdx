Each part — title, subtitle, body and actions — is a prop for plain text or a slot for anything
else. Parts you leave out aren't rendered.

  >

    </Fragment>
  </Card>
</Preview>

## Colors

With a `color`, `elevated` and `flat` cards get a solid background; `outlined` and `tonal` take the
color for the border or tint and the text.

The actions stay at the bottom when cards in a grid stretch to the same height.

## API

| Prop       | Type                                                               | Default             |
| ---------- | ------------------------------------------------------------------ | ------------------- |
| `title`    | `string`                                                           | —                   |
| `subtitle` | `string`                                                           | —                   |
| `text`     | `string` — body text                                               | —                   |
| `variant`  | `elevated` · `flat` · `outlined` · `tonal`                         | `elevated`          |
| `color`    | `primary` · `secondary` · `success` · `warning` · `info` · `error` | — (neutral surface) |
| `rounded`  | `xs` · `sm` · `default` · `lg` · `xl` · `full`                     | `default`           |
| `titleTag` | `h2` … `h6` · `div` — put the title in the heading outline         | `div`               |
| `class`    | `string`                                                           | —                   |

Any other attribute goes to the card's `<div>` — e.g. `data-theme="dark"` for a dark card.

| Slot       | Content                    |
| ---------- | -------------------------- |
| `title`    | replaces `title`           |
| `subtitle` | replaces `subtitle`        |
| default    | the body — replaces `text` |
| `actions`  | buttons at the bottom      |
