## Closable chips

`closable` adds a × button that removes the chip. Focus moves to the next chip's × button, so
keyboard users keep their place.

<Preview>
  <Chip closable text="Warszawa" />
  <Chip closable color="primary" text="Kraków" />
  <Chip closable color="secondary" variant="outlined" text="Gdańsk" />
</Preview>

```astro
<div id="cities">
  <Chip closable text="Warszawa" />
  <Chip closable text="Kraków" />
</div>

<script>
  // Fired on the chip before it's removed; preventDefault() keeps it.
  document.getElementById('cities')?.addEventListener('chip:close', (event) => {
    if (!confirm('Remove?')) event.preventDefault();
  });
</script>
```

A chip can't be both a link and closable — a button inside a link isn't valid HTML, and TypeScript
flags it.

## API

| Prop          | Type                                                               | Default     |
| ------------- | ------------------------------------------------------------------ | ----------- |
| `text`        | `string`                                                           | —           |
| `variant`     | `tonal` · `flat` · `elevated` · `outlined` · `text`                | `tonal`     |
| `color`       | a [theme or custom color](/guides/themes/#custom-colors) | — (neutral) |
| `size`        | `xs` · `sm` · `default` · `lg` · `xl`                              | `default`   |
| `rounded`     | `xs` · `sm` · `default` · `lg` · `xl` · `full`                     | `full`      |
| `prependIcon` | icon component (as for [`Icon`](/components/icon/))                | —           |
| `appendIcon`  | icon component                                                     | —           |
| `href`        | `string` — renders an `<a>`                                        | —           |
| `closable`    | `boolean` — not with `href`                                        | `false`     |
| `closeLabel`  | `string` — accessible name of the × button                         | `Remove`    |

| Slot      | Content                    |
| --------- | -------------------------- |
| default   | the text — replaces `text` |
| `prepend` | before the text            |
| `append`  | after the text             |

| Event        | When                                                                 |
| ------------ | -------------------------------------------------------------------- |
| `chip:close` | on the chip, before a closable chip is removed — cancelable, bubbles |
