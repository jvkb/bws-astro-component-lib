A menu that slides in over the page — the typical mobile navigation. Like
[`Dialog`](/components/dialog/) it's built on the native `<dialog>`: focus stays inside, the page
behind is dimmed and doesn't scroll, Escape closes it and focus returns to the menu button.

The default slot is wrapped in a `<nav>` and scrolls when it's long; the header (`title` or the
`prepend` slot, plus `closable`'s ×) and the `append` footer stay in place.

`left` and `right` drawers are full-height and `width` wide (`xs` 12rem, `sm` 14rem, `default`
16rem, `lg` 20rem, `xl` 24rem, or pixels), leaving a strip of the page visible on phones. `top`
and `bottom` drawers span the screen and are as tall as their content, at most 85% of the screen.

## Opening and closing

| To…                         | Use                                                          |
| --------------------------- | ------------------------------------------------------------ |
| open from a menu button     | the `activator` slot                                         |
| open from anywhere          | `data-drawer-open="drawer-id"` on any element                |
| close from inside           | `data-drawer-close`, or `closable` for a × button            |
| close a specific drawer     | `data-drawer-close="drawer-id"`                              |
| close when a link is clicked | on by default — `closeOnNavigate={false}` turns it off      |
| open or close in a script   | the native `drawer.showModal()` / `drawer.close()`           |

A click on the backdrop and Escape close it too, unless it's `persistent`. Closing on a link click
matters for links within the page (`#contact`): the drawer gets out of the way of the section the
link scrolls to.

## API

| Prop              | Type                                                | Default      |
| ----------------- | --------------------------------------------------- | ------------ |
| `location`        | `left` · `right` · `top` · `bottom`                 | `left`       |
| `title`           | `string` — in the header                            | —            |
| `label`           | `string` — accessible name of the navigation        | title, then `Navigation` |
| `width`           | `xs` · `sm` · `default` · `lg` · `xl` · number (px) — for `left` / `right` | `default` |
| `closable`        | `boolean` — a × button in the header                | `false`      |
| `closeLabel`      | `string` — accessible name of the × button          | `Close`      |
| `closeOnNavigate` | `boolean` — close when a link inside is clicked     | `true`       |
| `persistent`      | `boolean` — backdrop and Escape don't close it      | `false`      |
| `open`            | `boolean` — open on page load                       | `false`      |
| `titleTag`        | `h2` · `h3` · `div`                                 | `h2`         |
| `id`              | `string` — for `data-drawer-open`; generated when missing | —      |
| `class`           | `string`                                            | —            |

| Slot        | Content                                          |
| ----------- | ------------------------------------------------ |
| `activator` | the element that opens the drawer                |
| `prepend`   | the header content — replaces `title`            |
| default     | the navigation, inside a `<nav>`                 |
| `append`    | the footer, e.g. the signed-in user              |
