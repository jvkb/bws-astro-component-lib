## Buttons

| `controlVariant` | Buttons                      |
| ---------------- | ---------------------------- |
| `default`        | ▲ / ▼ stacked at the end     |
| `split`          | − at the start, + at the end |
| `hidden`         | none — arrow keys still step |

The buttons use the input's native stepping, so `min`, `max` and `step` are respected, and a button
turns off once its limit is reached. Each step fires `input` and `change`, like typing does. The
buttons keep focus in the field and are skipped by Tab — keyboard users step with the arrow keys.

## API

All [`TextInput` props](/components/text-input/#api) except `type`, plus:

| Prop                 | Type                            | Default    |
| -------------------- | ------------------------------- | ---------- |
| `controlVariant`     | `default` · `split` · `hidden`  | `default`  |
| `incrementLabel`     | `string` — accessible name of + | `Increase` |
| `decrementLabel`     | `string` — accessible name of − | `Decrease` |
| `min`, `max`, `step` | native attributes               | —          |
