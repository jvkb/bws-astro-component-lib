Items are strings, or `{ title, value, disabled? }` when the shown text differs from the submitted
value. The value lives in a hidden native `<select>`, so the field submits with the form, resets
and fires `input` / `change` like a native one. Opening the list needs JavaScript.

## Keyboard

It follows the WAI-ARIA select-only combobox pattern: focus stays on the field and screen readers
announce the highlighted option.

| Key                   | Action                                                            |
| --------------------- | ----------------------------------------------------------------- |
| ↓ / ↑ / Enter / Space | open the list                                                     |
| ↓ / ↑                 | move through options (skipping disabled ones)                     |
| Home / End            | first / last option                                               |
| Enter / Space         | choose the highlighted option                                     |
| Escape                | close without a change                                            |
| Tab                   | close and move on                                                 |
| letters               | jump to an option — repeat a letter to cycle, type more to narrow |

## Position

The list is positioned with [Floating UI](https://floating-ui.com): it isn't clipped by a parent
with `overflow: hidden` and follows the field while scrolling. `location` sets where it opens:

| `location`       | Opens                                       |
| ---------------- | ------------------------------------------- |
| `auto` (default) | below, or above when there isn't room below |
| `bottom`         | always below                                |
| `top`            | always above                                |

## API

| Prop          | Type                                          | Default   |
| ------------- | --------------------------------------------- | --------- |
| `items`       | `string[]` or `{ title, value, disabled? }[]` | required  |
| `name`        | `string` — form field name                    | —         |
| `value`       | `string` — initially selected value           | —         |
| `label`       | `string`                                      | —         |
| `placeholder` | `string`                                      | —         |
| `variant`     | `filled` · `outlined` · `underlined`          | `filled`  |
| `color`       | focus color                                   | `primary` |
| `location`    | `auto` · `bottom` · `top`                     | `auto`    |
| `hint`        | `string`                                      | —         |
| `error`       | `string` — starts out invalid                 | —         |
| `rules`       | [validation rules](/guides/validation/)       | —         |
| `disabled`    | `boolean`                                     | `false`   |
| `id`, `class` | `string` — `id` goes to the focusable field   | —         |
